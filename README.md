# Loopsquare Tech — Official Web Platform

> **Ideas Into Intelligent Solutions**  
> Scalable Cloud Solutions & Modern Responsive Web Development

Built with **React 19**, **React Router v7**, **Tailwind CSS v4**, and **Vite** based on the GQ Consultants application template.

---

## 🚀 Key Features & Pages

- **Home Page (`/`)**:
  - High-impact branding with the Loopsquare Tech emblem and logo.
  - Value metric highlights: *99.99% Cloud Reliability*, *40% Avg Cost Savings*, *100+ Solutions Delivered*, *24/7 Monitoring*.
  - Interactive Filterable Grid for all **8 Core Services**.
  - Company narrative teaser (*"Empowering Businesses Through Technology"*).
  - Why Choose Us showcase (6 pillars).
  - **Interactive Project & Cost Estimator widget**.
  - Enterprise Technology Stack showcase (AWS, Azure, GCP, React, TypeScript, Node.js, Docker, Kubernetes).
  - Client Success Stories & Testimonials.
  - High-converting Call-to-Action banner (*"Let's Build Your Digital Future Together"*).

- **Services Directory (`/services`)**:
  - Filter by Cloud Infrastructure vs. Web & Software Engineering.
  - Comprehensive service cards with capabilities, business benefits, and technology stacks.
  - Interactive **Service Capability Matrix** table.

- **Dedicated Service Architecture Pages (`/services/:slug`)**:
  - `/services/cloud-solutions`
  - `/services/website-development`
  - `/services/cloud-migration`
  - `/services/cloud-cost-optimization`
  - `/services/cloud-security-management`
  - `/services/ecommerce-development`
  - `/services/web-application-development`
  - `/services/website-maintenance-support`
  - Each featuring: Executive summaries, 4-step implementation methodology, tangible deliverables checklist, tech stack, and service FAQs.

- **About Us (`/about`)**:
  - *"Empowering Businesses Through Technology"*.
  - Full company story and philosophy.
  - **Our Mission**: *"To empower businesses with innovative, secure, and affordable technology solutions that drive growth and digital transformation."*
  - **Our Vision**: *"To become a trusted technology partner for businesses worldwide by delivering reliable solutions, continuous innovation, and exceptional customer experiences."*
  - **Why Choose Us?** (Customer-focused, Secure cloud, Modern websites, Cost-effective, Dedicated support, Quality & innovation).
  - Core engineering principles.

- **Contact Us (`/contact`)**:
  - Interactive discovery and quote request form with dynamic pre-selection from services or estimator.
  - Direct contact channels, headquarters address, phone, and 24/7 SLA emergency line.

---

## 🛠️ Tech Stack

- **Framework**: [React Router v7](https://reactrouter.com/) (SSR & Client Routing)
- **UI Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Bundler & Tooling**: [Vite](https://vitejs.dev/) + TypeScript

---

## 💻 Running the Application

### Development Server
```bash
npm install
npm run dev
```
The application will be live at `http://localhost:5173/`.

### Production Build
```bash
npm run build
npm run start
```
